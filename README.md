# Z-pin 金属丝植入控制系统

用于科研实验中的碳纤维管金属丝植入，协调三维移动模组、变距伺服、植入滑台和上下气阀，完成定位、夹丝、植入、退针及人工剪丝之间的控制流程。

## 硬件组成

| 组件 | 作用 |
| --- | --- |
| TwoTrees TTC450 Pro 三维移动模组 | 通过串口发送 G 代码，控制植入模组的 XYZ 位置 |
| 五工位变距模组与汇川 SV630N 伺服 | 通过 EtherCAT 调节工位间距；当前预设安装最右两针，针距固定为 10 mm |
| GX28 滑台与 2830 步进电机 | 由 ESP32 控制针头可动部分的植入与退针 |
| 上下气阀 | 配合滑台完成金属丝的夹持与释放 |

## 主要功能

- **实机植入**：用户版每排包含三个工作区，每区支持 7、10、15 根预设，架角 0°、15°、30°，植入深度可设；区间空白距离按沿管长度输入并保存。
- **完全自定义**：分别控制 CNC、伺服、滑台和气阀，并支持单次植入。
- **配置记忆**：保存命名机器配置、接口选择及对刀点，实机与自定义共用配置。
- **人工协作**：等待剪丝确认，支持原位重做、排间转管与收工。
- **运行记录**：保存实验过程及结果，保留报警、急停和位置校验。

## 软件与交付

上位机使用 Python 和 Tkinter，提供 Windows 用户版图形界面，并保留独立调试界面与命令行工具。ESP32 固件随源码提供。

交付采用目录版 EXE，用户无需安装 Python 或 conda；使用 EtherCAT 伺服时需安装 Npcap。源码、构建文件和运行配置相互独立，个人配置、实验记录及构建产物不上传仓库。
