# Z-pin 金属丝植入机控制系统

用于科研实验中的碳纤维管金属丝植入。TTC450 Pro控制XYZ位置，SV630N通过EtherCAT控制五工位变距模组，GX28/2830滑台与上下气阀完成夹丝、下针、换夹和退针。

当前提供 **预设任务** 和 **完全自定义**。图形界面与终端共用业务逻辑，设备协议和GPIO12防复位连接方式沿用现有版本。

## 预设任务

20 mm强化区，只装最右两根针，针距固定10 mm，伺服保持机械零位。每次选择植入根数、架角θ和植入深度。

| 每排根数 | 点距 mm | 扎针动作数 | 区内覆盖 mm |
|---|---|---|---|
| 7 | 3.333333 | 4 | 0–20 |
| 10 | 2 | 5 | 0–18 |
| 15 | 1.428571 | 8 | 0–20 |

10根预设不要求20 mm端点。7/15根补针时第二根针会落在30 mm处，记录中保留该区外落点；需保证余料和夹具允许，再人工切除。

针竖直，管子架斜。θ仅支持0°、15°、30°，正角表示管面朝+X上升。排内工作高度按 `z=z0+(x-x0)*tanθ` 跟随；安全高度不得低于整排最高工作点。
深度沿垂直管面量，只要求有限且大于0，不再设置工艺上限；滑台行程为 `depth/cosθ`，目标仍须落在已确认的工作窗口内。两根针的针长差为 `10*tanθ`，不同架角需要匹配的针组。固件软件窗口为−30～+30 mm，对刀待机位−15 mm时可再下行15 mm：0°深度15 mm可达软件边界；30°深度15 mm需下行约17.321 mm，向导在连接设备前报告行程越界。取消工艺上限不会取消运动窗口检查。GX28标称总行程50 mm，±30 mm软件窗口并不表示两侧都各有30 mm机械余量；必须按人工零位确认实际可用行程。
对刀以已装两针中的左针为排头，整排保留本次对刀Y。先人工确认GX28软件零点及下方15 mm机械余量，保持针尖离开工件；程序把滑台下移到−15 mm，再手动调整CNC完成对刀。对刀确认后弹窗输入GX28上升距离（默认15 mm，范围0–15 mm），程序上升并回读、记录剪丝安全位置；15 mm对应0，3 mm对应−12。旧5/10 mm准备配置重新对刀时采用新默认15 mm；新15 mm准备流程中已保存的自选距离会继续沿用。CNC排间Z安全高度仍单独确认。

自动植入先让GX28保持已记录的剪丝安全位（默认0 mm），CNC移到落点并确认到位后，才把GX28降回对刀待机位（默认−15 mm），再按 `待机位-depth/cosθ` 下针。退针后滑台回对刀待机位，再上升15 mm到默认剪丝安全位0，电机保持使能、B阀保持夹紧；剪丝完成且双手离开后按回车或界面「继续」，松开B阀并保持剪丝安全位，CNC移到下一落点后才下降植入。首点、落点之间和排间回排头均保持该安全位，最后一次确认后也不下降。每个落点包括末针都等待剪丝确认。一排完成后CNC抬至排间安全高度回排头，人工转管后继续；`D`表示排间正常收工，`!`请求急停。上升距离设为0时剪丝位等于对刀待机位，保留立即释放B阀的旧流程。

## 完全自定义

一个页面同时提供伺服针距/微动/使能/设零、滑台下行/回待机/设零、气阀A/B分别通排气、CNC XYZ移动/回零/解锁、单次注入和命名配置。终端提供同样的平铺动作菜单。
一次点击执行一个动作。单次注入保持CNC坐标，按当前针距与滑台行程执行夹丝、下针、换夹、退针、剪丝抬升，停住等待；人工剪丝后点击「剪丝完成，松上阀并保持安全位」，滑台保持抬高，此时可手动移动CNC；下一次点击植入才下降回对刀位。等待剪丝时禁止重新植入、移动机构或改零位；停止或关闭不自动下降。

**滑台输入是下行行程，不是沿垂直管面量的植入深度**；仍受机器配置中已确认的工作窗口约束。伺服针距10–20 mm，内部换算为0到−10 mm。
每次上电后必须核实机械待机位与靠紧零位，软件显示0不能证明机械零位。微动每次最多0.5 mm。急停后重新确认零位。

## 配置保存

向导保存串口、EtherCAT网卡、滑台工作窗口、对刀待机位置、剪丝安全位置和上升距离到模板旁的 `config.local.toml`。距离在实机对刀后输入，实机、自定义读取同一 `[cycle] cut_clearance_mm` 和 `[head] standby_mm/cut_safe_mm`。命名机器配置在 `profiles/machines/`，向导完成后同步更新本次所选机器配置；命名自定义设定在 `profiles/custom/`，只保存针距、滑台行程和XYZ目标。加载自定义配置不会动作或恢复气阀/使能状态。

CNC XYZ行程限位由下位机负责，上位机不再配置或校验工作坐标上下界；旧配置中的 `x_max/y_max/z_max` 字段不再使用。对刀位置与排间安全高度仍在同一工作坐标系中记录；安全高度必须不低于整排最高工作点。CNC返回的错误和Alarm仍会中止动作，GX28工作窗口检查保持有效。

本次需要烧录当前 `firmware/insert_head/insert_head.ino`，只扩大软件运动窗口至−30～+30 mm，协议仍为2，GPIO12接线与串口防复位方式保留。窗口是相对人工零位的软件限位，并非新增物理限位开关。上位机在运动准备前读取固件状态核对窗口；旧版−10～0 mm或±15 mm固件不满足新窗口时会提前报错，不开始预下降或植入。烧录后通过实机向导重新确认零位、准备并对刀；旧配置不自动变成已确认的新坐标，也不会自动扩大其已确认的较窄窗口。自定义单次植入按记录的对刀待机位定位工件；独立气阀不受窗口升级检查阻挡。交付目录也附带同版固件源码，后续手动烧录。
配置菜单可导入并命名机器配置，再选择已有机器或自定义配置。自定义配置在面板里保存；当前选择在 `profiles/selection.toml`。没有档案时仍使用模板叠加本机配置。
`[job]` 默认值为 `angle_deg/count/depth_mm`；CLI明确传入的 `--angle/--count/--depth` 覆盖本次默认值。旧作业方案和 `--length/--spacing` 已移除。

## 运行

```powershell
conda activate zpin
$env:PYTHONNOUSERSITE = '1'
python -B master/gui_main.py
python -B master/master.py
python -B master/master.py --smoke-test
python -B master/master.py --simulate --count 10 --angle 30 --depth 3
python -B master/master.py --live
```

终端菜单：1实机、2仿真、3自检、4调试输出、5配置档案、6完全自定义、7预设任务（先选实机或仿真）。预设入口每次询问密度、角度、深度。
`--live` 进入交互向导；非交互实机还需 `--confirm-datum --datum-x <x0> --datum-z <z0>`，并补齐实测配置。`--rows N` 跑N排后正常收工。缺少前提时在连接前拒绝。

自检不连接硬件，预期 `已完成：12 个落点，共 3 排（每排 4 个）`、`阀门已关闭`，退出码0。这里“落点”指一次扎针动作，区内每排有7个植入位置。
按影响范围验证，模型切换完成后运行一次完整回归：

```powershell
python -B -m unittest discover -s tests -q
```

实机结果逐动作写入CSV和JSON摘要（默认 `runs/`），中止也记录。调试输出显示设备回话，CNC状态轮询按变化折叠。

## 图形界面与交付

窗口内可运行预设、仿真、自检、配置管理和完全自定义。运行中禁止启动另一个流程；关闭窗口先请求停止并等待设备收尾。
目录版交付包含 `ZpinControlUI.exe`、`ZpinControl.exe` 和共用运行库，用户无需Python或conda，首次需安装Npcap。构建说明见 [交付说明](packaging/README.md)。修改源码不会自动更新已有EXE。

本轮离线验收不代表新两针预设已实机验证；实际针尖基准、30 mm补针余料、夹具间隙及运动响应仍需现场核对。
设计见 [预设与自定义](docs/superpowers/specs/2026-10-08-preset-and-custom-design.md)，历史和验证记录见 [开发日志](DEVELOPMENT_LOG.md)、[环境说明](ENVIRONMENT.md)。
