# Z-pin 金属丝植入机控制系统

用于科研实验中的碳纤维管金属丝植入。TTC450 Pro控制XYZ位置，SV630N通过EtherCAT控制五工位变距模组，GX28/2830滑台与上下气阀完成夹丝、下针、换夹和退针。

当前提供 **预设任务** 和 **完全自定义**。图形界面与终端共用业务逻辑，设备协议和GPIO12防复位连接方式沿用现有版本。

## 预设任务

20 mm强化区，只装最右两根针，针距固定10 mm，伺服保持机械零位。每次选择植入根数、架角θ和植入深度。

| 每排根数 | 点距 mm | 扎针动作数 | 区内覆盖 mm |
|---|---|---|---|
| 7 | 3.333333 | 4 | 0–20 |
| 10 | 2 | 5 | 0–18 |
| 15 | 1.428571 | 8 | 0–20 |

10根预设不要求20 mm端点。7/15根补针时第二根针会落在30 mm处，记录中保留该区外落点；需保证余料和夹具允许，再人工切除。

针竖直，管子架斜。θ带符号（±45°内），正值表示管面朝+X上升。排内工作高度按 `z=z0+(x-x0)*tanθ` 跟随；安全高度不得低于整排最高工作点。
深度沿垂直管面量，必须大于0且不超过3 mm；滑台行程为 `depth/cosθ`。两根针的针长差为 `10*tanθ`，正负角需要匹配的针组。
对刀以已装两针中的左针为排头。每次退针并释放B阀后人工剪丝，按回车或界面「继续」才进入下一落点。一排完成抬至安全高度回排头，人工转管后继续；`D`表示排间正常收工，`!`请求急停。

## 完全自定义

一个页面同时提供伺服针距/微动/使能/设零、滑台下行/回待机/设零、气阀A/B分别通排气、CNC XYZ移动/回零/解锁、单次注入和命名配置。终端提供同样的平铺动作菜单。
一次点击执行一个动作。单次注入保持CNC坐标，按当前针距与滑台行程执行一次夹丝、下针、换夹、退针、释放；完成后人工剪丝，再手动开始下一次。

**滑台输入是下行行程，不是植入深度，不经过预设的3 mm深度限制**；仍受机器配置中已确认的工作窗口约束。伺服针距10–20 mm，内部换算为0到−10 mm。
每次上电后必须核实机械待机位与靠紧零位，软件显示0不能证明机械零位。微动每次最多0.5 mm。急停后重新确认零位。

## 配置保存

向导保存串口、EtherCAT网卡、CNC软限位、滑台工作窗口和安全高度到模板旁的 `config.local.toml`。命名机器配置在 `profiles/machines/`；命名自定义设定在 `profiles/custom/`，只保存针距、滑台行程和XYZ目标。加载自定义配置不会动作或恢复气阀/使能状态。
配置菜单可导入并命名机器配置，再选择已有机器或自定义配置。自定义配置在面板里保存；当前选择在 `profiles/selection.toml`。没有档案时仍使用模板叠加本机配置。
`[job]` 默认值为 `angle_deg/count/depth_mm`；CLI明确传入的 `--angle/--count/--depth` 覆盖本次默认值。旧作业方案和 `--length/--spacing` 已移除。

## 运行

```powershell
conda activate zpin
$env:PYTHONNOUSERSITE = '1'
python -B master/gui_main.py
python -B master/master.py
python -B master/master.py --smoke-test
python -B master/master.py --simulate --count 10 --angle -30 --depth 3
python -B master/master.py --live
```

终端菜单：1实机、2仿真、3自检、4调试输出、5配置档案、6完全自定义、7预设任务（先选实机或仿真）。预设入口每次询问密度、角度、深度。
`--live` 进入交互向导；非交互实机还需 `--confirm-datum --datum-x <x0> --datum-z <z0>`，并补齐实测配置。`--rows N` 跑N排后正常收工。缺少前提时在连接前拒绝。

自检不连接硬件，预期 `已完成：12 个落点，共 3 排（每排 4 个）`、`阀门已关闭`，退出码0。这里“落点”指一次扎针动作，区内每排有7个植入位置。
按影响范围验证，模型切换完成后运行一次完整回归：

```powershell
python -B -m unittest discover -s tests -q
```

实机结果逐动作写入CSV和JSON摘要（默认 `runs/`），中止也记录。调试输出显示设备回话，CNC状态轮询按变化折叠。

## 图形界面与交付

窗口内可运行预设、仿真、自检、配置管理和完全自定义。运行中禁止启动另一个流程；关闭窗口先请求停止并等待设备收尾。
目录版交付包含 `ZpinControlUI.exe`、`ZpinControl.exe` 和共用运行库，用户无需Python或conda，首次需安装Npcap。构建说明见 [交付说明](packaging/README.md)。修改源码不会自动更新已有EXE。

本轮离线验收不代表新两针预设已实机验证；实际针尖基准、30 mm补针余料、夹具间隙及运动响应仍需现场核对。
设计见 [预设与自定义](docs/superpowers/specs/2026-10-08-preset-and-custom-design.md)，历史和验证记录见 [开发日志](DEVELOPMENT_LOG.md)、[环境说明](ENVIRONMENT.md)。
