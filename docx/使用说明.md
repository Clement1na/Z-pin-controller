# 使用说明

1. **打开程序**：进入 `dist/ZpinControl`，双击 `ZpinControlUI.exe`。交付时保留整个文件夹，无需安装 Python 或 conda。
2. **选择接口**：点击“接口与机器配置”，选择已有机器配置，或命名保存新配置；核对 CNC 串口、GX28 串口及需要使用的伺服网卡。
3. **设置任务**：点击“实机运行”，选择每区根数、架角、植入深度，填写区间空白距离（沿管长度）；三个区共用本次参数，保存的间距会在下次打开时预填。
4. **确认零位**：按提示确认 GX28 的机械零位与可用行程；使用伺服时，确认其处于机械靠紧位。
5. **完成对刀**：选择重新对刀，按提示调整 CNC 并确认；程序记录位置、抬针。可保存对刀点，下次在工件、针组及坐标基准未改变时复用。
6. **开始植入**：核对摘要，点击“开始植入”；也可选择“仅保存，暂不运行”。
7. **剪丝与继续**：每次等待剪丝时，处理完金属丝并让双手离开，点击“继续”或按回车。本次未做好时，可选择“原位重做本次植入”。
8. **换排或结束**：程序依次完成三个区，区间自动移动；第三区剪丝确认后回第一区排头，等待人工转管，再继续下一排的三个区。结束时选择“排间收工”，需要立即停止时使用“急停”。

## 三个工作区的距离

每个区保留原有双针与X方向20 mm排程。填写的空白距离，是从前一区名义X=20 mm末边到后一区起点的沿管距离，不是CNC的X移动量，也不是相邻区域起点间距。

若空白为g、架角为θ，相邻区域起点位移为 `ΔX=20+g*cosθ`、`ΔZ=20*tanθ+g*sinθ`。例如30°、空白40 mm，第二、第三区相对第一区的起点X偏移为54.641、109.282 mm，Z偏移为31.547、63.094 mm；Y不变。跨区与回排头前均先确认GX28抬针到0。

三个区合起来才算一排，每区7/10/15根时，整排分别为12/15/24次双针动作。只有整次作业的最开始一次不套丝，之后包括跨区、换排与重做都沿用1.5 mm套丝。

7/15根保留原区外补针：末次另一根针落在相对本区起点X=30 mm处，可能进入名义空白段，需留出余料。摘要显示的三区总长不包含该部分；管长约200 mm不作为程序硬编码的行程限制，运行前请按摘要核对工件与夹具。

## 单独控制组件

完成接口配置后，进入“完全自定义”，选择伺服、滑台、气阀、CNC 或单次植入动作。该入口与实机运行共用机器配置。
