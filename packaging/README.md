# Z-pin 用户版使用说明

解压后双击 `ZpinControlUI.exe`。整个文件夹需一同保留，不能只复制exe；无需安装Python或conda。使用EtherCAT伺服时，首次需安装Npcap。

## 三个入口

1. **接口与机器配置**：选择已有命名配置，或填写名称保存为新配置；同页选择伺服有线网卡、CNC串口、GX28串口。上次仍可用的接口优先显示，Wi-Fi、虚拟网卡、蓝牙串口及非USB串口隐藏。扫描失败仍显示具体原因；特殊接口可勾选“手动填写未列出的接口”。保存配置不会连接或移动机构。
2. **实机运行**：先完成接口选择，再在一页选择每排7/10/15根、架角0/15/30°及垂直管面的植入深度。按提示确认开机机械零位，完成CNC对刀；对刀点保存选项与开始确认合并。可选择“仅保存，暂不运行”。
3. **完全自定义**：使用同一套机器及接口配置，分别控制伺服、GX28、气阀、CNC或执行单次植入。按动作连接所需设备；缺席伺服不阻止气阀等独立操作。未连接的组件仍显示错误。

## 实机流程

开机前人工确认GX28位于机械零位、下方有15 mm余量，针尖离开工件；装最右两针、针距10 mm，连接的伺服位于机械靠紧位。软件显示0不能证明机械归零。

新建对刀时，程序将GX28从0下移到−15 mm；手动调整CNC，使两针中的左针刚好接触管面，然后确认。程序记录CNC XYZ，将GX28上抬15 mm到0并回读。用户版不再询问上抬距离或独立CNC排间安全Z，架角0/15/30°均固定抬15 mm。

对刀点可随当前机器配置保存。下次可复用或重新对刀；只有工件、针组和CNC工作坐标基准均未改变时才能复用。开机零位仍须确认；架角、接口或标定变化时需重新对刀。

自动植入在GX28=0、气阀释放后移动CNC，确认抬针到位才移动。CNC工作高度沿 `Z=Z0+(X−X0)*tanθ` 跟随斜面，Y保持本次对刀位置；排间保持GX28=0，沿工作斜面返回排头，不另抬CNC到用户设定的安全Z。斜向植入行程为 `深度/cosθ`。本版没有修改植入深度或1.5 mm套丝公式。

整个作业第一次先到对刀位−15 mm再植入。后续落点、换排首点和原位重做：上阀B夹紧，GX28到对刀位上方1.5 mm（−13.5），松B、夹下阀A，再下到原有最终植入目标。以0°、深度3 mm为例，最终位置每次都是−18 mm。

退针后先回−15，再抬到0；B保持夹紧，电机保持使能。剪丝完成、双手离开后点击“继续”或按回车，B排气，GX28保持0，然后移向下一点。等待剪丝时可选择“原位重做本次植入”，不移动CNC或伺服，完成后再次等待。排间人工转管后继续；收工与急停保留原按钮。

7/10/15根分别需要4/5/8次扎针动作。7/15根末次用左针补区内最后一根，右针落在相对排头30 mm的余料处，需留足余料与夹具空间。

## 配置与数据

`config.local.toml`保存本机设置，命名机器配置在`profiles/machines`，自定义动作参数在`profiles/custom`，实验记录在`runs`。实机与完全自定义共用本包内的机器配置。加载配置不会恢复气阀状态或自动移动机构。另存名称已存在时请从列表选择后修改，避免误覆盖另一机器的标定和对刀点。

CNC行程限位由下位机负责，上位机保留坐标有效性、报警和急停检查。GX28仍核对固件协议2、±30 mm软件工作窗口及位置回读；窗口不等于实际机械余量。本次UI更新不修改ESP32固件，也不需要为此重新烧录。

自定义关闭时，若操作过的伺服不在10 mm针距或位置无法确认，可选“归零后退出 / 取消 / 强制退出”。只用气阀不会为退出额外连接伺服。

## 调试版与构建

原完整调试界面保存在相邻`ZpinControlDebug`文件夹，入口`ZpinControlDebug.exe`，其中也保留命令行`ZpinControl.exe`。两包各自保存配置与实验记录；首建调试包复制当前机器设置，以后分别保留。调试版仍采用原独立CNC安全Z向导。

开发机运行 `powershell -File packaging/build.ps1` 构建两包。脚本在独立目录构建、核对运行库，安全关闭旧控制窗口后才覆盖，并保留最新配置、档案、记录及上一份完整包。使用指定环境可传`-Python <python.exe路径>`。
